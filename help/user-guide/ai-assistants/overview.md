# Übersicht über KI-Assistenten

[!DNL GenStudio for Performance Marketing] stellt über das Model Context Protocol (MCP) eine Verbindung zu unterstützten KI-Assistenten her. Sobald die Verbindung hergestellt ist, können Sie die Anzeigenleistung abfragen, kreative Anzeigen zusammenstellen und genehmigte Anzeigen über Konversationen in natürlicher Sprache veröffentlichen.

## Unterstützte KI-Assistenten

Sie können eine Verbindung über diese unterstützten KI-Assistenten-Pfade herstellen:

| KI-Assistent | Verbindungspfad |
|---|---|
| Adobe CX Enterprise Coworker | Native, von Ihrem Unternehmen verwaltete Verbindung |
| Claude | Remote-MCP-Connector |
| ChatGPT im Web | Remote-MCP-Connector im Entwicklermodus |
| Codex | Remote-MCP-Verbindung über die Befehlszeile konfiguriert |
| Schriftstellerin | Benutzerdefinierter Remote-MCP-Connector |
| Microsoft Copilot | Mit Microsoft-Anleitung konfigurierte Remote-MCP-Verbindung |

Siehe [Verbinden eines KI-Assistenten](connect-ai-assistants.md) für eine Einrichtungsanleitung.

## Funktionen

Sobald die Verbindung hergestellt ist, kann ein KI-Assistent in drei Arbeitsbereichen helfen:

- **Insights:** Erhalten Sie Überschriften-KPIs, finden Sie Ihre Anzeigen mit der besten und schlechtesten Leistung, verstehen Sie, warum eine Anzeige auf eine bestimmte Weise funktioniert, und erhalten Sie Empfehlungen, die auf Ihren Leistungsdaten basieren.
- **Erstellen** Durchsuchen Sie Vorlagen, stellen Sie einen bearbeitbaren Entwurf aus einer Vorlage oder Empfehlung zusammen und geben Sie den Entwurf zur Überprüfung und Genehmigung frei.
- **Aktivieren** Suchen Sie ein genehmigtes Erlebnis, lösen Sie das Veröffentlichungsziel auf und veröffentlichen Sie es in einem verbundenen Kanal.

Die unterstützten Kanäle variieren je nach Funktion. Insights deckt für die meisten Berichte Meta, LinkedIn und Innovid ab. Benutzerdefinierte Konversionsmetriken decken Meta und LinkedIn ab.

Erstellen umfasst Meta, LinkedIn, Display, TikTok und YouTube. Activate gilt für Meta, LinkedIn und Google Campaign Manager 360. Siehe die [KI-Assistenten-Tools](tools-reference.md) für die Kanalunterstützung jedes Tools.

## Zugriff und Berechtigungen

KI-Assistentenfunktionen sind im Allgemeinen für Kunden verfügbar, die für [!DNL GenStudio for Performance Marketing] aktiviert sind. Sie benötigen ein gültiges Adobe-Konto mit Zugriff auf das Produkt.

Die Verbindung verwendet Ihre Adobe-Identität und respektiert Ihre bestehenden Produktberechtigungen. Sie können nur auf Organisationen, Paid-Media-Konten, Kampagnen und Daten zugreifen, die Ihr Konto bereits anzeigen kann.

Jede Verbindung wird zu einer Adobe Identity Management System (IMS)-Organisation zusammengefasst. Stellen Sie erneut eine Verbindung her und wählen Sie eine andere Organisation aus, wenn Sie wechseln müssen.
